# Backtesting Engine from Scratch

A simple Python backtesting engine built from scratch to understand how trading strategies are converted into measurable performance.

## Features

* OHLCV data handling
* Strategy signal generation
* Order execution and portfolio tracking
* PnL calculation
* Sharpe ratio
* Maximum drawdown
* Turnover
* Transaction costs & slippage
* Look-ahead bias experiments

## Goal

The main goal is to understand the complete pipeline:

**Market Data → Signal → Order → Execution → Portfolio → Performance**

and learn how common backtesting issues such as **look-ahead bias, survivorship bias, and transaction costs** affect results.
